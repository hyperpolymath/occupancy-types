= occupancy-types Retraction Ledger
:toc:
:icons: font

Policy (ULTRAPLAN §3, §1.3): every rung ships a pre-written kill criterion.
When a kill criterion fires — or a claimed result turns out to be wrong — the
claim is *retracted here*, not quietly re-scoped. A retraction names the claim,
the evidence that killed it, and the rung affected. Kill-criterion firing stops
that rung; it does not start a redefinition.

This ledger also records *blocked* rungs (environment missing, fixture
requested). Blocked ≠ retracted: no claim has been withdrawn.
